# Statute 1 — Intent Is Absolute

*Movement: Document · Stream: validate*

## The law

Published: "Never exceed specification. Refine intent; do not patch symptoms."

Completion †: "An emergency patch owes the spec an update within one cycle."

## Violation

"Hotfixing AI output without updating the spec."

## Limits

The published detail already allows true emergencies to be patched, followed by a spec
update within one cycle; the one-line principle did not say so, and read alone it forbade
the right act. A typo fix exceeds no spec. The edge against hotfix culture stays.

## Conformance

Checked today: the spec changes before the code; the receipt cites the spec version; an
emergency patch opens a spec-debt line on the trail. Direction: the tool flags a delivered
unit whose spec version postdates none of its code changes.
