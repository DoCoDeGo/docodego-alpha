# Dogfood — independent agent builds a product on 0.7.2

Recorded: 2026-11-08. A fresh temp repo, the published npm package, and an
independent agent given nothing but the folder and the binary. It picked
its own product (`mdtasks` — a markdown task extractor, zero deps, 6
passing tests), planted the record, and walked the loop. Its findings were
then independently verified — every claim below is confirmed or falsified
with evidence, per the record law.

The dogfood repo (throwaway, in the approved temp area) ends in the best
state possible: the unit **delivered**, the failed attempts preserved in
the append-only log, 6 clean conventional commits, check/lint/doctor
green.

## Good

- **The tool teaches itself.** Per-command `--help` documents exit codes
  and contracts before they bite; `--version` prints both axes.
- **`sketch` earns its promise** — near-zero ceremony, forward-guiding
  output that prints the exact graduation command.
- **Grill rounds are honest** — failed rounds are recorded, not erased;
  `trace` replays the pass/fail/pass timeline. Writing answers forced the
  maker to pre-think failure modes — and one predicted failure then
  happened.
- **The score floor is real but fair** (83/100 first try); the scaffold's
  "lazy specs stay below the floor by construction" claim held.
- **Gate output is calm and precise** — four labeled gates, `FAIL G4`,
  exit 1, nothing committed on red.
- **`doctor` is a real triage sweep** — 9/9 including skills-lockfile
  digest verification.
- **The full loop works end to end** — a first-time agent delivered a
  unit with zero human guidance on the golden path.

## Bad (verified)

1. **The proof-path grammar is undocumented and brittle.** G4 extracts
   only the *first whitespace token* of each `proofs.md` list item
   (`proofPaths` in `passes/check.ts`). The natural writing shape —
   `- AC1 — \`command\` suite…` with the path on a continuation line —
   yields the token `AC1`, not a path. An independent agent burned seven
   attempts and invented hypotheses (absolute paths, doubled roots)
   against a gate whose message, `none of 9 path(s) exist on disk`,
   never names the pseudo-paths it extracted (they were first words of
   the attempts log: "record-root-relative", "absolute", "bare"…).
   Only `- <path>` first-token items pass. This is the one shape the
   README shows — which is why 176 conformance checks stay green while a
   real user fails.
2. **`check` and `deliver` disagree.** While G4 refused, `check` returned
   `record holds together` and `doctor` reported 9/9 — neither exercises
   the gate's proof-existence logic, so all health indicators are green
   while the gate that matters is red.
3. **`score`'s shown reasoning can be fiction.** Against a ~100-word
   bullet-list scope it reported `scope is thin (<5 words)` — the
   heuristic counts prose paragraphs and misses list shape. The total
   still passed, but a user trying to improve the score is reading made
   -up notes. (The subagent's other score complaint — testability — was
   a misreading on their side; the note was correct.)
4. **Grill quotes struck-through criteria as live questions.** After an
   append-law amendment (old AC struck inline, restated below), the grill
   generated a question quoting the dead criterion including its `~~`
   markers — the parser has no notion of superseded text. Append-only
   amendment and the grill's AC parser are mutually incompatible as
   shipped.
5. **README record-tree drift.** The tracker lives at
   `04-govern/01-monitor/tracker.md`, not `.docodego/tracker.md` as the
   README's tree shows.
6. **README overpromise:** "A failed gate … the attempt is recorded" is
   false for `deliver` refusals — a refused gate writes no record trace
   (verified: refused attempts left the tracker untouched; the maker had
   to hand-append its own attempts log to honor the reconstruction law).

## Ugly

1. **"The delivery gate is welded shut" — the maker's headline claim —
   FALSIFIED, and the falsification is the finding.** A single
   path-first line (`- <record-root-relative-path>`) delivered the unit
   immediately (`GATE PASS mdtasks — delivered`). The gate works; the
   grammar is undiscoverable. Nothing in `deliver --help`, the
   `DG-C002` explain page, or any skill states the first-token rule, and
   the error output hides the extracted tokens. This is the highest-value
   fix in the list.
2. **init plants a dangling law reference.** The planted AGENTS.md says
   to read `.docodego/.standard/guidelines/pattern.md` before any unit —
   init does not plant that file (`.standard/` carries manifest,
   statutes, tech-radar, vocabulary only). check/lint do not flag the
   dangling reference.
3. **The bundled skills speak a foreign dialect.** Six shipped skills
   (`docodego`, `-loop`, `-compose`, `-demonstrate`, `-document`,
   `-govern`) reference `.framework/` and `03-rising/` layouts the
   planted record v5 tree does not have, and one gates delivery on an
   `assurance.md` the CLI neither plants nor reads. Installed craft and
   planted record disagree — digest-verified all the way down.
4. **`init`'s refusal doesn't name the directory it inspected** — running
   it against the wrong CWD reports `refusing: .docodego/ already exists`
   for a tree the user can't see (minor, but it cost the maker a
   false hypothesis).

## What this test proves about the system

The conformance suite pins the golden path and cannot see the writer's
path: every check replayed the README's exact shapes, so a tool where a
natural variant silently fails ships with 176 green checks. An
independent first-time agent found, in one session, what the suite
structurally cannot. Dogfooding with fresh eyes is not optional
insurance — it is the only check that runs the *promise* instead of the
*implementation*.

## Fix list (proposed for 0.7.3)

1. G4: document the grammar in `deliver --help` + the `DG-C002` page;
   accept paths appearing anywhere in an item (not only first token);
   make the failure message list the extracted tokens (capped).
2. `check`: exercise the G4 proof-resolution logic (or grow a
   `check --gates` mode) so health and gates can't disagree.
3. init: plant `guidelines/pattern.md` (or stop referencing it); lint
   flags dangling AGENTS.md references.
4. score: make the completeness heuristic parse list items, not just
   prose.
5. grill: treat struck-through lines as superseded (skip question
   generation).
6. Docs: fix the README tracker path; fix the "attempt is recorded"
   claim (or record deliver refusals for real).
7. Skills: sync the bundled method skills to the planted record v5
   dialect.
