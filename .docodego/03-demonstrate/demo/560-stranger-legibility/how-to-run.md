# how to run

The demo is the stranger's path: refuse a proofs-less unit and watch
the help arrive with the wall.

## see it work

    docodego new legibility-demo --stream 02-compose/01-build
    … grill + score it, then, with no proofs.md written:
    docodego deliver legibility-demo
    docodego explain G4

Expected: the GATE FAIL names G4 and a note announces the scaffold —
.docodego/02-compose/01-build/010-legibility-demo/proofs.md now
exists, teaching the path grammar (a fill-these list, no planted
phantoms). The second deliver re-refuses without rewriting your
edits. And the gate's own id now explains itself: meaning, law, fix.

    docodego score legibility-demo --json > /dev/null; docodego score legibility-demo

Expected: each axis row carries its note — the why sits on the same
line as the number.
