# how to run

Filled by the agent at demonstration time; read by the founder's
"show me it working" and the launch auditor (an unfilled scaffold
refuses the launch gate). Write how a cold reader sees this unit work.
Scratch captures live in var/ or here as paths — the honesty law
recognizes paths, not pasted binaries. One honest line is a valid fill:
"the suite is the demo" is a show.

## see it work

1. `tail -40 docs/process/enhancements.md` — the disposition table:
   every box in one state, done boxes naming child units, declines
   with their standing reasons.
2. `pnpm -C apps/cli run -s conformance` — 488 green; the three
   "650:" facts are the least-privilege pin.
3. The pin's teeth: add a permission line to
   `.github/workflows/ci.yml` and re-run — the facts go red (revert
   after; the pin asserts the default surface).

## run output

`node apps/cli/src/main.ts check` — exit 0; no payload hop (the shelf
and workflows sit outside the boundary). proofs.md lists each path.
