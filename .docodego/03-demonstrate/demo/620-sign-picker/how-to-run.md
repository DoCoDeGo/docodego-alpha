# how to run

The demo is the founder's own question, answered by the tool.

## see it work

    node apps/cli/src/main.ts sign

on a terminal: the launch-passed units list numbered — pick by
number or name, or type `all`; empty input cancels with nothing
appended. The batch, headless:

    node apps/cli/src/main.ts sign --all --yes

Expected right now: `nothing to sign — no launch-passed units await
the founder tier` (exit 0) — the first live batch already cleared
the waiting room (450, 460, 470, 480 signed with the provisional
marker, receipts on file). The refusal world:

    node apps/cli/src/main.ts sign

piped (non-TTY) refuses with DG-U119 naming the contract; the
explain page says the same:

    node apps/cli/src/main.ts explain DG-U119

## run output

`conformance: all 482 checks green` — 2026-11-09, in the committed
state, recorded in the unit's proofs.md.

## visual evidence

none — a numbered list and an honest batch are the show.
