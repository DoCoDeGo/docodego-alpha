## intent

The v27 test round's stranger-test passed on refusals but flagged
three legibility gaps, each costing a cold walker one avoidable
lookup: (1) proofs.md is the one artifact with no scaffold — every
walker hit the G4 refusal and had to find the grammar in deliver
--help, while launch's L5 repair already scaffolds how-to-run.md
beside the refusal (the precedent this unit mirrors); (2) the score
gate computes a per-axis note ("3 criteria, 2 without an observable
marker") but the printed rows drop it — the why exists, unseen, and
three agents independently reported scoring with no reason; (3) gate
IDs are not explainable — `docodego explain DG-G4` finds nothing
because gates never joined the diagnostic registry. One theme: the
refusal (and the score) tells the walker everything, in the message,
at the moment of failure.

## scope

In: deliver plants a create-only proofs.md scaffold beside the G4
refusal and names it in the refusal (mirroring launch's L5 repair);
score's human rows print each axis's note; the explanation registry
gains the nine gates (GATE-G1..G4, GATE-L1..L5 — meaning, law, fix)
under a GATE family, and explain normalizes a bare gate ID (G4, l2)
to its GATE- page; conformance pins for all three. Out: any payload
or record-contract change (all three are engine code — bundle stays
at spec 27); the message nits held for their own batch (init's
planted count, status counters' history, new's echoed renumbering,
check's terse green line); the founder-tier marker (held for the
founder's ruling).

## acceptance

- A G4 refusal on a proofs.md-less unit exits 1, refuses as before,
  and leaves a create-only proofs.md scaffold in the unit folder
  that shows the path grammar; a filled proofs.md is never
  rewritten.
- score's rows carry their axis note — a weak axis prints its own
  why on the same line.
- `docodego explain G4` (and L2, l2, GATE-L5) prints
  meaning/law/fix; unknown codes still refuse as usage errors; the
  DG- families and --list behave as pinned before.
- Full battery green: check, conformance (count grows), bundle
  verify clean at spec 27, pnpm run doctor, docs fresh, build 11/11.
